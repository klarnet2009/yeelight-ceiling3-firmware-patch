# Прошивка готового образа

Инструкция для готового образа со страницы
[Releases](https://github.com/klarnet2009/yeelight-ceiling3-firmware-patch/releases):
`yeelink.light.ceiling3-hybrid-2.0.2_0048.bin`. English version: [FLASHING.md](FLASHING.md).

> **Сначала прочитайте.**
> - Образ проверен на **одной** лампе: YLXD17YL, модель `yeelink.light.ceiling3`, модуль MT7697N, стоковая прошивка
>   `2.0.2_0048`. Другие ревизии платы и другие модели не проверялись.
> - Прошивка неофициальная. Если на вашей лампе она не загрузится, вернуть лампу можно только через UART на плате.
>   Удалённо помочь с восстановлением никто не сможет.
> - Образ представляет собой прошивку Yeelight `2.0.2_0048` с изменениями объёмом около 2.5 КБ. Проект не связан с
>   Yeelight, Xiaomi и MediaTek и ими не одобрен.

## Что понадобится

- Лампа, добавленная в Mi Home, подключённая к вашему Wi-Fi и **уже обновлённая до `2.0.2_0048`** (обновите её в
  Mi Home заранее).
- Компьютер в той же локальной сети, на котором **свободен TCP-порт 80 и он доступен лампе** (разрешите его в
  брандмауэре; в Linux и macOS для порта 80 нужны права root). Лампа скачивает образ с этого компьютера и умеет
  обращаться только к порту 80.
- Python 3 и три пакета:

  ```
  pip install cryptography requests qrcode
  ```

- Этот репозиторий (клонируйте или скачайте ZIP) и файл образа из релиза, положенный в корень репозитория.

## 1. Проверьте скачанный файл

Сравните контрольную сумму с указанной в описании релиза:

```
certutil -hashfile yeelink.light.ceiling3-hybrid-2.0.2_0048.bin SHA256      (Windows)
sha256sum yeelink.light.ceiling3-hybrid-2.0.2_0048.bin                      (Linux/macOS)
```

Кроме того, `miio_ota.py` откажется отправлять файл, который не проходит проверки контейнера (SHA-1 заголовка и
сегментов, CRC, LZMA).

## 2. Получите токен лампы

```
python xiaomi_qr_token.py de
```

Вместо `de` укажите свой регион Mi Home (`cn`, `de`, `us`, `ru`, `sg`, `i2` и так далее). Скрипт сохранит QR-код
входа в `xiaomi_login_qr.png`; отсканируйте его приложением Mi Home в течение примерно 5 минут. После входа скрипт
покажет список устройств и запишет токен лампы `yeelink.light.ceiling3` в `token.txt`. Если таких ламп несколько,
укажите адрес нужной в переменной `LAMP_IP` в начале скрипта.

`token.txt` и картинка с QR-кодом — секреты: не публикуйте их (оба файла внесены в `.gitignore`).

Проверьте, что это именно та лампа, для которой сделан образ (подставьте адрес своей лампы):

```
python miio_ota.py check --ip=192.168.0.20
```

Команда сравнивает то, что лампа сообщает о себе, с проверенной конфигурацией: модель `yeelink.light.ceiling3`,
прошивка `2.0.2_0048`, чип `MTK7697`, прошивка Wi-Fi-ядра `20190110183129`. Все четыре строки должны быть `OK`.
Если хотя бы одна показывает `MISMATCH`, не продолжайте.

Команда `flash` выполняет ту же проверку и откажется отправлять образ на другое устройство или на другую версию
прошивки. Отказ можно обойти ключом `--force`; делайте это, только если можете восстановить лампу через UART.
Ревизии платы, которые сообщают одинаковые значения, проверка различить не может.

## 3. Первая прошивка: через облако Xiaomi

Стоковая прошивка отклоняет команду обновления, пришедшую по локальной сети, поэтому в первый раз команда
отправляется через ваш аккаунт Xiaomi. Сам образ лампа всё равно скачивает с вашего компьютера:

```
python miio_ota.py flash yeelink.light.ceiling3-hybrid-2.0.2_0048.bin --ip=192.168.0.20 --cloud=de
```

Когда скрипт попросит, снова отсканируйте QR-код, затем нажмите Enter для отправки команды. Скрипт показывает ход
работы: `downloading` с процентами, `installed`, пауза около минуты на перезагрузку лампы и в конце
`lamp rebooted; back online`. При перезагрузке свет один раз погаснет и включится. Не отключайте питание во время
установки.

Если скрипт сообщил `NO REBOOT within 10 min`, ничего не установлено: лампа не смогла скачать файл. Проверьте, что
порт 80 открыт и не занят другой программой.

## 4. Следующие прошивки: по локальной сети

Когда на лампе уже стоит изменённая прошивка, команда обновления принимается по локальной сети, вход в облако не
нужен:

```
python miio_ota.py flash <образ.bin> --ip=192.168.0.20 --yes
```

## 5. Проверьте результат

Номер версии остаётся `2.0.2_0048`, поэтому проверяйте по поведению:

- в дневном режиме яркость 1 теперь даёт тусклый ночник (лунные светодиоды), а яркость 10 — самый слабый уровень
  основных светодиодов; приложение по-прежнему показывает дневной режим;
- читается журнал событий:

  ```
  python tools/read_bblog.py --ip=192.168.0.20
  ```

  В нём должна быть запись о загрузке и выход сети в «облако».

## Возврат к стоку

Прошейте исходный файл Xiaomi `yeelink.light.ceiling3-stock-2.0.2_0048.bin`
(MD5 `13b7471a0f84e3cfbac78c116fae7a1c`) так же, как в шаге 4. Здесь этот файл не распространяется; в README_RU.md
перечислены источники с описанием того, как запросить его у облака Xiaomi.

## Что изменится в обычной работе

- В дневном режиме яркость 1–9 дают лунные светодиоды, 10–100 — основные. На тёплом свете переход между 9 и 10
  не виден; на нейтральном и холодном яркость 10 заметно ярче, чем 9.
- Если у лампы 5 минут нет сети, она сама перезагружается (свет один раз мигнёт). Если сеть так и не появилась,
  следующие перезагрузки будут через 30 минут и затем раз в 6 часов.
- Расписание ночного режима, поведение при включении, пульт и работа с Mi Home не меняются.
